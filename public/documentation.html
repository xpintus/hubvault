1System Overview

What HubVault does and why it exists

HubVault brings all your cash reconciliation into one dashboard

HubVault is a cash reconciliation and collection tracking system built for logistics, courier, and delivery companies that handle Cash-on-Delivery (COD) operations across multiple hubs or branches.

The system tracks the complete cash flow journey: from the moment a field collector returns with cash, through reconciliation against expected amounts, to final deposition at the bank or Cash Management System (CMS). It flags shortages, tracks outstanding dues, manages recovery collection, and provides full audit trails.

📊

Daily Reconciliation

🏦

Multi-Hub Support

Manage multiple branches/hubs from a single account with hub switching

💵

Dues & Recovery

Key Benefit: No more spreadsheets or manual tracking. Every rupee is accounted for — from collection to deposition — with a complete audit trail.

3License Generation & Activation System

How license keys work — from generation to activation

License keys secure every Hub Admin account

The license system ensures that only authorized branch managers can access the system. Every Hub Admin account is tied to a unique license key that must be activated within 24 hours of account creation.

How It Works — Step by Step

  1. Account Creation by Super Admin

    When the Super Admin creates a new Hub Admin account, the system automatically generates a unique 16-character license code in the format XXXX-XXXX-XXXX-XXXX. The code appears on screen for the Super Admin to share with the Hub Admin.

  2. Hub Admin Logs In

    The Hub Admin logs in with their email and password. They go straight to the dashboard — an activation popup appears on top of the dashboard with a countdown timer showing the time remaining to activate.

  3. Activation Popup — Two Options

    The Hub Admin can either: (a) enter the license code immediately and click "Activate", or (b) click "Skip for now" to dismiss the popup and use the dashboard for the remaining time.

  4. Using Dashboard Without Activation (24-hour grace period)

    If the Hub Admin skips activation, a yellow warning banner stays at the top of the dashboard showing the live countdown. They can click "Activate Now" at any time to re-open the activation popup. The dashboard works normally during this period.

  5. 24-Hour Deadline Passes — Account Locked

    If the Hub Admin does not activate within 24 hours, the account is automatically locked. They are signed out and cannot log back in until the Super Admin generates a new license code.

  6. Super Admin Regenerates License (if needed)

    If a license expires or the Hub Admin loses their code, the Super Admin can generate a new one from the License Management page. This creates a fresh code and restarts the 24-hour clock.

License Statuses

StatusMeaningDashboard Access
Pending License generated, not yet activated. 24-hour countdown running. Full access with activation popup & warning banner
Activated License code entered successfully. Account is permanent. Full access, no restrictions
Expired 24 hours passed without activation. Account is locked. Blocked — cannot log in until new code is issued
No Key No license key generated yet (rare — only for very old accounts). Super Admin can generate one from License Management

For Hub Admins: You have 24 hours from the moment your account is created to enter your activation code. You can use the dashboard during this time, but if you don't activate before the timer runs out, you will be locked out. Contact your Super Admin immediately if you lose your code.

For Super Admins: You can view all licenses, generate new codes, and regenerate expired ones from the License Management page. The code is shown only once — make sure to copy it and share it securely with the Hub Admin.

The heart of the system — track every rupee collected

The dashboard shows a complete picture of daily collections

The Dashboard is the main working screen. It shows the day's collections for the selected hub, with powerful filtering, reconciliation status, and detailed breakdowns.

Key Information at a Glance

Every cash entry tracks note counts: ₹500, ₹200, ₹100, ₹50, ₹20, ₹10, ₹5, ₹2, ₹1

Collection Entry Details

Each collection entry records:

  • Collection Date — the day the cash was collected
  • Collector — which field employee collected the cash
  • Expected COD — the amount that was supposed to be collected
  • Cash Amount — physical cash collected (with denomination breakdown)
  • Online Amount — digital payments (UPI, bank transfer, other)
  • Total Collection — cash + online combined
  • Gap — difference between total and expected (negative = shortage, positive = excess)
  • Status — automatically set: Reconciled, Pending, Shortage, or Excess
  • Remarks — optional notes about the collection

Reconciliation Status Logic: If the total collection exactly matches the expected COD, the entry is "Reconciled". If less cash was collected than expected, it's a "Shortage". If more was collected, it's "Excess". If the entry is not yet complete, it's "Pending".

Date Navigation

The dashboard has a date toolbar at the top. You can move to the previous or next day, jump to "Today", or pick any date from the calendar. All data on the page updates for the selected date and hub.

6Reports & Analytics

Gain insights from your collection data

Reports give you trends and performance metrics

The Reports page provides aggregated analytics across your collection data. It is available to Super Admins, Hub Admins, and Supervisors.

Reports include collection trends over time, reconciliation rates, top-performing collectors, shortage/excess analysis, dues aging, and recovery performance. All reports are hub-scoped (showing data for the currently selected hub) or show "All Hubs" for Super Admins.

Reports can also be exported to Excel for offline analysis or sharing with management.

7Dues & Recovery Management

Track outstanding amounts and collect them back

Track every outstanding rupee until it's recovered

Dues

When a collector has a shortage (collected less than expected), the shortfall amount becomes a Due. The Dues page tracks all outstanding amounts owed by collectors. Each due records:

  • Original Amount — the full shortage amount
  • Recovered Amount — how much has been paid back so far
  • Remaining Amount — what's still outstanding
  • Due Date — when the amount became due
  • Status — Outstanding, Partially Recovered, or Fully Recovered

Recovery

Recovery records payments made by collectors to clear their dues. Each recovery entry tracks the payment date, amount, payment mode (cash, online, other), reference number, and notes. When a recovery is recorded:

  1. The recovery is logged with full details
  2. The parent due's recovered amount increases and remaining amount decreases
  3. The due status automatically updates to "Partially Recovered" or "Fully Recovered"

Recovery access for collectors: Field collectors can record their own recovery payments directly from the Recovery page, making it easy to update the system as they collect outstanding amounts.

8CMS Deposition (Cash Deposit Tracking)

Track cash deposited at the bank or Cash Management System

Verify that all collected cash reaches the bank

After cash is collected and reconciled, it must be deposited at the bank or Cash Management System (CMS). The Deposits page tracks this final step in the cash flow.

Each deposit entry records:

  • Deposit Date — when the cash was deposited
  • Total Cash Collected — cash collected that day
  • Cash Deposited — actual amount deposited at CMS/bank
  • Online Amount — digital payments (no deposit needed)
  • Short Amount — any shortfall between collected and deposited cash
  • Reference Number — deposit slip or transaction reference
  • Remarks — additional notes

Why this matters: The CMS Deposition feature closes the loop. It ensures that the cash collected by field employees actually reaches the bank. Any shortfall between collected cash and deposited cash is immediately flagged.

9Employee Management

Manage your field collectors and their records

The Employees page (called "Collectors" in the system) is where you manage all field staff who collect cash. Each employee record includes their name, employee ID, phone number, and assigned hub.

Employee Profile

Clicking on an employee opens a detailed profile showing:

  • Today's collection amount
  • Total collection (all time)
  • Total pending dues
  • Total recovered amount
  • Current outstanding due
  • Full history of dues and recoveries

You can also record a recovery payment directly from the employee profile — select the due, enter the amount, and save.

10User & Access Management

The Users & Access page is where Super Admins and Hub Admins create and manage system users. Depending on your role, you can create:

  • Super Admin can create: Hub Admins, Supervisors, Collectors
  • Hub Admin can create: Supervisors, Collectors (for their hub only)

When creating a Hub Admin, the system automatically generates a license code (see Section 3). For other roles, no license is needed.

Additional features on the Users page:

  • Search & filter users by name, email, or role

  • Assign multiple hubs to Hub Admins

11Excel Import & Export

Bulk data entry and offline reporting

Import and export collection data in Excel format

Export to Excel

From the Dashboard, you can export all collection entries for the current date and hub to an Excel file (.xlsx). The export includes all fields: collector name, expected COD, cash amount, online amount, total, gap, status, denominations, and remarks. The filename includes the date and hub code for easy identification.

Import from Excel

Managers (Super Admins, Hub Admins, and Supervisors) can bulk-import collection entries via an Excel file. This is useful for entering historical data or when multiple entries need to be added at once. The import validates the data and creates entries in the system.

Tip: Use the Export function first to get a template with the correct column structure, then fill in new data and use Import to add entries in bulk.

13Audit Logs

A complete record of who did what, and when

Every important action is logged for accountability

The Audit Logs page (Super Admin only) provides a complete trail of all important actions in the system. Every time a user creates, updates, or deletes something significant, an audit log entry is created recording:

  • Action — what was done (e.g., "Hub Created", "User Updated", "License Regenerated")
  • Performed By — which user did it
  • Target — which user or hub was affected
  • Details — a human-readable description of the action
  • Timestamp — when the action occurred

Why this matters: Audit logs provide full accountability. If there's ever a dispute or discrepancy, you can trace exactly who made which change and when.

16Security & Data Protection

How your data is kept safe

Bank-grade security protects your data
🔐

Row-Level Security

Every database table has row-level security enabled — users can only see and modify data for their assigned hubs.

🔑

License-Based Access

Hub Admin accounts require license activation within 24 hours, preventing unauthorized access.

📝

Full Audit Trail

Every significant action is logged with user, timestamp, and details — no change goes unrecorded.

🎭

Role-Based Access

Six distinct roles ensure users only see features and data relevant to their job function.

Your data is safe: All data is stored in a secure PostgreSQL database with encryption at rest. Authentication is handled by Supabase Auth with industry-standard JWT tokens. Passwords are never stored in plain text.
